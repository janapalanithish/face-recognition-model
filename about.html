About This Project

What Is RecognizeMe AI?

RecognizeMe AI is a browser-based face recognition tool that allows users to detect and verify faces in real time using their webcam. It uses modern AI models and JavaScript to process data instantly without requiring heavy backend systems.

Who Built This?

I am a final year engineering student from Hyderabad, India. This project was built as part of my learning journey in artificial intelligence, machine learning, and web development. My goal was to create a practical application that demonstrates real-world use of AI technologies.

Why I Built This

Traditional authentication systems like passwords and ID cards have limitations. I built this tool to explore how biometric systems like face recognition can provide a more secure and seamless user experience.

Technology Stack

  • HTML5 — structure and layout
  • CSS3 — styling and responsiveness
  • JavaScript — logic and AI integration
  • Firebase — secure data storage
  • Vercel — hosting and deployment
  • Domain — Namecheap (Github Student Developer Pack)
